Fundcure

Fundraising Mobile Application – Flutter + Firebase

📌 Project Overview

Fundcure is a fundraising mobile software developed using Flutter and Firebase. This project was created in my second year at university and focuses on enabling users to easily create, manage, and donate to fundraising campaigns.

🚀 Features

  • User authentication with Firebase
  • Create & manage fundraising campaigns
  • Real-time data updates
  • Secure cloud storage
  • Modern UI/UX with Flutter

🛠 Tech Stack

Flutter Dart Firebase Auth Cloud Firestore Firebase Storage
